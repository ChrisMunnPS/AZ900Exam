AZ-900 cheat sheet 1/3 — Describe cloud concepts

One page. Facts snapshot 2026-11; verify current behaviour on Microsoft Learn before the exam.

What cloud computing is

ItemWhat to remember
DefinitionDelivery of computing services over the internet, usually with consumption-based pricing.
Provider dutiesPhysical datacenters, hosts, storage hardware, and the global network.
Customer dutiesData, identities, access, and the configuration of whatever the service exposes.
Consumption modelPay for what you use; release the resource and the meter stops. No upfront hardware.
CapEx vs OpExBuying servers is capital expenditure; cloud usage is operating expenditure.
Economies of scaleProviders buy and operate at massive scale, lowering the cost per unit.

Deployment models

ModelWhat it means
PublicProvider-owned, multi-tenant, delivered over the internet. Azure, Microsoft 365.
PrivateCloud-style pooling dedicated to one organisation, on site or hosted.
HybridPrivate or on-premises connected to public cloud for regulatory, latency, or legacy needs.
Multi-cloudServices from more than one public provider; reduces lock-in.
SovereignIsolated Azure instance for legal or compliance reasons (US Government, China).

Service models

ModelYou manage / Microsoft manages
IaaSYou: OS, runtime, apps, data. Microsoft: hosts, storage, virtualization. Example: Virtual Machines.
PaaSYou: code and data. Microsoft: OS, runtime, scaling, patching. Example: App Service, Azure SQL.
SaaSYou: users, data, settings. Microsoft: the entire application. Example: Microsoft 365.

If you patch the guest OS you are in IaaS; if you only bring code you are in PaaS; if you only configure a finished product you are in SaaS.

Shared responsibility

LayerIaaSPaaSSaaS
Physical datacenter, hosts, networkMicrosoftMicrosoftMicrosoft
Hypervisor and host OSMicrosoftMicrosoftMicrosoft
Guest OS and runtimeCustomerMicrosoftMicrosoft
Application codeCustomerCustomerMicrosoft
Data, identities, accessCustomerCustomerCustomer
Device and account hygieneCustomerCustomerCustomer

Always customer: data, accounts, permissions, and configuration. Always Microsoft: the physical and virtualization layer.

Benefits and characteristics

TermMeaning
High availabilityMinimal downtime through redundancy, health probes, and fast failover.
ReliabilityKeeps working correctly and recovers from failures.
ScalabilityAdd or remove capacity: scale up (bigger) or scale out (more instances).
ElasticityAutomatic scaling that matches capacity to demand.
PredictabilityConsistent performance and a forecastable cost.
AgilityProvision, change, and tear down resources in minutes.
Geo-distributionDeploy to multiple regions to reduce latency for users.
Disaster recoveryRestore service and data after a major event; measured by RTO and RPO.
ManageabilityManage through portal, CLI, PowerShell, APIs, and templates.
Security & governanceCentral policy, identity, and compliance over certified infrastructure.

Resilience vocabulary

TermPlain meaning
RTORecovery time objective — how long the service may be down.
RPORecovery point objective — how much data loss is acceptable.
Fault toleranceThe system keeps running when a component fails.
ServerlessRun code on demand without provisioning servers; pay per execution.

Exam traps

  • Public cloud does not mean public data; it means provider-owned, shared infrastructure.
  • Cloud removes hardware management, not your responsibility for data and access.
  • Scalability is capability; elasticity is automation.
  • “Minimal changes and OS control” points to IaaS; “no server management” points to PaaS or serverless.
  • Hybrid combines private with public; multi-cloud combines public providers.

AZ-900 cheat sheet 2/3 — Azure architecture and services

One page. Facts snapshot 2026-11; verify current behaviour on Microsoft Learn before the exam.

Physical and management structure

ItemWhat to remember
RegionGeographic area with one or more datacenters on a low-latency network. Most resources are regional.
Availability zonePhysically separate datacenter group in a region with independent power, cooling, and networking. Zone-enabled regions have at least three.
Region pairSame geography, at least 300 miles apart; updates roll out one at a time; data stays in the geography (Brazil South excepted).
Sovereign regionIsolated Azure instance: US Government, China via 21Vianet.
Global servicesMicrosoft Entra ID, Azure DNS, and Traffic Manager are not tied to one region.
Resource groupFlat container; a resource is in exactly one group; deleting the group deletes its contents.
SubscriptionBilling and access-control boundary; one tenant can have many subscriptions.
Management groupGroups subscriptions for inherited policy and access; 6 levels below the root, 10,000 per directory, one parent.
HierarchyTenant root → management groups → subscriptions → resource groups → resources.

Compute

ServiceUse it for
Virtual MachinesFull OS control, lift and shift, legacy apps. You patch the guest OS.
VM scale setsIdentical, load-balanced VMs that scale out and in automatically.
Availability setsSpread VMs across fault domains and update domains inside one datacenter.
Container InstancesFastest way to run one container; no orchestration; per-second billing.
Kubernetes ServiceOrchestrate a large fleet of containers.
Azure FunctionsEvent-driven serverless code; pay per execution; Durable Functions keep state.
App ServicePaaS web apps, APIs, mobile back ends; deployment slots and autoscaling.
Virtual DesktopManaged Windows desktops and apps streamed to users.

VM families: B burstable · D general · E memory · F compute · M large memory · L storage · N GPU.

Networking

ServiceWhat it does
Virtual networkPrivate IP networking with isolation, segmentation, and routing. Subnets divide the address space.
Network security groupAllow/deny rules by priority on a subnet or NIC.
VPN GatewayEncrypted site-to-site, point-to-site, or VNet-to-VNet tunnel over the internet.
ExpressRoutePrivate dedicated circuit that does not traverse the public internet.
Azure DNSPublic zone hosting; private zones resolve names inside VNets.
Load BalancerLayer 4 (TCP/UDP) distribution with health probes.
Application GatewayLayer 7 reverse proxy: URL path routing, TLS termination, optional WAF.
Front DoorGlobal anycast HTTP entry: latency routing, failover, caching, edge WAF.

Storage

ServiceWhat it holds
Blob storageUnstructured objects: images, video, backups, logs. Tiers: hot, cool (30-day min), cold (90-day min), archive (180-day min, offline).
Azure FilesManaged SMB and NFS file shares, mountable by Windows, Linux, and macOS.
Queue storageMessages that decouple application components.
Table storageNoSQL key-value store for structured, non-relational data.
Storage account3–24 characters, lowercase letters and numbers only, globally unique; sets region, performance, and redundancy.

Redundancy: LRS = 3 copies in one datacenter · ZRS = 3 zones in one region · GRS = LRS plus region copies · RA-GRS = GRS with a readable secondary · GZRS = ZRS plus region copies.

Identity and security

ItemWhat to remember
Microsoft Entra IDCloud identity provider for users, groups, apps, and devices.
AuthN vs AuthZAuthentication proves identity; authorization decides what is allowed.
MFATwo or more factor types: know (password), have (authenticator), are (biometrics).
Conditional AccessIf-then sign-in policy using user, device, location, app, and risk signals.
Single sign-onOne authentication for many applications.
B2B / B2CB2B invites partners as guests; B2C serves consumers in your apps.
RBACRole assignment at management group, subscription, resource group, or resource.

AI and IoT

ServiceUse it for
Azure AI servicesPrebuilt vision, speech, language, and document APIs — no model training.
Azure OpenAIGenerative AI chat and content with Azure security and governance.
Azure Machine LearningBuild, train, and manage custom models.
IoT HubSecure bidirectional device-to-cloud and cloud-to-device messaging.
IoT CentralSimplified SaaS IoT platform for solution builders.
IoT EdgeRun cloud workloads close to devices.

Exam traps

  • Zones protect inside a region; region pairs protect across regions.
  • A resource belongs to one resource group, and groups cannot be nested.
  • Storage account names cannot contain uppercase letters, hyphens, or underscores.
  • Load Balancer is layer 4; Application Gateway is regional layer 7; Front Door is global layer 7.
  • Available zones do not exist in every region; the minimum is three where they do.

AZ-900 cheat sheet 3/3 — Azure management and governance

One page. Facts snapshot 2026-11; verify current behaviour on Microsoft Learn before the exam.

Cost management

ToolUse it for
Pricing calculatorEstimate the monthly cost of a planned set of Azure services.
TCO calculatorCompare an existing on-premises estate with the equivalent Azure cost.
Cost analysisReview actual spend and trends by resource, group, service, or tag.
BudgetsSet a spending target and alert on actual or forecast thresholds. Budgets warn; they do not block spend.
TagsName-value metadata for cost allocation, ownership, and environment. Not inherited automatically.
AdvisorFree recommendations for cost, reliability, security, performance, and operational excellence.
ReservationsCommit for one or three years for a lower rate on predictable workloads.

Cost drivers: region, resource size, running time, storage volume and tier, transactions, and outbound (egress) data. Deallocating idle resources is the fastest saving.

Governance

ControlWhat it does
Azure RBACAssigns a role to a user, group, or identity at a scope; permissions inherit downward.
OwnerFull access including granting access.
ContributorCreate and manage resources, cannot grant access.
ReaderView resources only.
User Access AdminManage access only, not resources.
Azure PolicyEnforces what resources may look like: regions, tags, SKUs. Evaluates create and update requests.
Policy effectsDeny, Audit, Append, Modify, DeployIfNotExists, AuditIfNotExists, Disabled.
LocksCanNotDelete blocks deletion; ReadOnly blocks changes and deletion. Apply to everyone, including Owners.
TagsOrganise and report; a resource does not inherit its group's tags automatically.

RBAC vs Policy: RBAC controls who can do what; Policy controls what the result may look like. A policy Deny blocks even subscription Owners.

Monitoring

ToolWhat it shows
Azure MonitorCentral platform for metrics, logs, alerts, dashboards, and workbooks.
MetricsNumeric time series, near real time; platform metrics are automatic.
LogsDetailed records in Log Analytics, queried with KQL (where, summarize, project, bin, join).
Activity logControl-plane audit: who created, changed, or deleted a resource.
Alert ruleThe condition: metric threshold, log query, or activity event.
Action groupThe response: email, SMS, voice, push, webhook, function, Logic App, runbook, ITSM.
Application InsightsRequest, dependency, exception, and performance telemetry for apps.
Service HealthAzure incidents, planned maintenance, and advisories for your services.
AdvisorPersonalised recommendations in five categories.
Defender for CloudSecurity posture, secure score, and workload protection across clouds.

Your resources vs the platform: Azure Monitor watches what you deployed; Service Health reports what Microsoft is doing.

Deployment and tooling

ToolNotes
Azure portalWeb GUI for creating and managing resources.
Azure CLICross-platform commands such as az group create.
Azure PowerShellCmdlets such as New-AzResourceGroup in the Az module.
Cloud ShellBrowser terminal with CLI and PowerShell preinstalled and authenticated.
ARM templatesDeclarative JSON describing the end state; idempotent redeploys.
BicepDeclarative language that compiles to ARM JSON; same engine, cleaner syntax.

Declarative vs imperative: a template describes the destination; a script describes the steps. Only the template is naturally idempotent.

Compliance, privacy, and agreements

ItemWhat it covers
Trust CenterPublished security, privacy, and compliance information and certifications.
Service Trust PortalAudit reports and compliance evidence for customers.
Privacy StatementWhat personal data Microsoft collects and how it is used and protected.
Compliance ManagerAssesses your tenant against ISO 27001, GDPR, and similar standards.
SLAAvailability commitment with service credits if missed; not a guarantee of zero downtime.
Preview featuresMay change or be withdrawn and are typically excluded from the standard SLA.
